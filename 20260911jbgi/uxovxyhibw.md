# 【集团动态】江湾高中教师招聘会在我院举行

> 更新时间：2026-09-11 (UTC+8)

**2022年1月15日，江湾高中第二场教师选拔招聘会在江湾集团旗下长沙江湾医院顺利举行。从千余份投递的简历中筛选出的近百位中青年教师参加了此次选拔招聘会，并有10位出众教师通过严格考评，脱颖而出，与学校当场签约，加盟江湾。**

此次招聘会场选定在集团旗下江湾医院

本场教师招聘会由江湾高中会同集团总部人事部门和江湾医院行政部门，展开跨部门联动，紧密协作，精心安排，严格遵守疫情防控有关规定，本着“公平、公正、公开”和“择优录用”的基本原则，制定了严谨清晰、目标明确的考核选拔程序，设定了资格审查、笔试、宣讲、片段教学、现场答辩等多个环节，优中选优，力求卓越，成功为学校选聘到了一批菁英教师。

本场招聘笔试环节分为专业笔试、素养考核两个部分，由来自长郡的正高特级教师姚建民组织各学科领域的资深特级专家教师，科学精准化命题，制作规范化试卷，按照标准化考试流程进行，限定时间，严格监考，测出了水平。

其中专业笔试主要考察应聘老师的学科知识水平，素养考核则要求以“美好教育成就美好江湾高中”为题，写一篇命题作文，不仅在于考察应聘老师的基本写作能力、思维能力，更在于考察其对江湾高中教育理念的理解与认识，旨在寻找符合江湾高中文化理念，志同道合的优秀教师。

**在宣讲环节，校长蔡芳在江湾医院报告厅结合自身的从教经历，讲述了她从湖南长郡到北京人大附中担任副校长，再到与江湾结缘，出任江湾高中校长，北渡南归，回馈桑梓，立志为教育事业奉献终身的心路历程，表达了一名新时代教育工作者的情怀与梦想，生动阐述了江湾高中“以父母之心办教育”的办学初衷和“让每一个学生成为美好的人”的育人理念，令在座老师们深受鼓舞。**

宣讲结束后，老师们与工作人员一起在江湾医院食堂共同享用了精心准备的丰盛午餐。饭后工作人员向老师们分发了各学科试讲课题，老师们则根据课题进行一小时备课准备，进入更具实战意味的面试（试讲和答辩）环节。

面试环节根据学科性质，划分为文科、理科和艺体（美术、音乐、体育）三个小组分别进行。来自长沙四大名校等的江湾高中特级名师专家团队以定性与定量考核相结合的基本原则，综合参考应聘教师整体形象气质、基本素养、教学设计能力、课程实施能力、认知水平、思辨能力、教育理念和价值观等多个维度，进行分项打分，精准评价，综合评估。**其中英语教师在参加校长面试时，更由蔡芳校长与应聘老师全程使用英语双向沟通，以真实场景应用考察了英语老师的听说能力。**

**此次前来应聘的老师们均****毕业于湖南大学、湖南师范大学、南华大学、北京外国语大学、陕西师范大学等全国重点大学，拥有本科、硕士、**博士学位的高层次人才。**负责英语学科选拔的刘淑英特级教师特别高兴地介绍说：“此次英语应聘教师水平相当不错 ，功底很深厚，有两名分别来自北外和湖大的英语硕士**当场就签了。**”**

**本次招聘现场，经过评委综合评价、校长亲自面试后，选拔出了一批专业扎实、素质一流、出类拔萃的青年教师，**并有10名特别优秀者与学校当场签约。

江湾高中语文教师马智君（语文特级）、江湾高中英语教师刘淑英（原师大附中英语特级）、黄敏兰（长沙市六中历史正高特级）、宋素珍（长沙教育学院政治学科负责人）等文科组评委

江湾高中物理教师程悦康（原雅礼中学物理正高特级）、唐亮（长沙教育学院数学学科负责人）、谢贵香（开福区教研中心理科室主任）、庄晋（株洲市教科院生物特级）等理科组评委

艺体组谭淑（南雅中学美术首席名师）、张朝飞（长沙教育学院音乐学科负责人）、王大鹏 （长沙教育学院体育学科负责人）等评委

蔡校长听取专家对应聘者的反馈

  **   ****通过在江湾医院举办骨干教师招聘会，让应聘老师们以亲身体验、耳濡目染的方式，对学校总部江湾集团的整体实力、产业结构和业务版图有了清晰直观的认识，从而对集团充满仁爱公益精神的企业文化增强了认同感，更对成为一名江湾高中教师增强了荣誉感和使命感，更加坚定信念奔赴江湾美好教育。**获益于江湾集团从优生优孕到医疗健康，再到高端教育及细胞生物科技、品质康养的全生命周期产业链，江湾高中教师作为集团职工将在广阔的发展前景中获得健康与事业的双丰收。**这场为期一整天的骨干教师选拔招聘会在集团各单位通力协作，紧密配合，精准把控下，为学校遴选到了一批有理想、有情操、有才华的魅力教师，进一步夯实了江湾高中的师资结构，补充了一批敬业、乐业、专业的中坚有生力量，为学校2022年秋季正式招新开学打下了稳固基础，更为江湾学子学有所得、进步成才提供了有力保障。**

长沙江湾医院创新开展生殖、妇科、中医、超声、遗传、男科等多学科联合诊疗，从由传统的各科室“单兵作战”，转变为专家多对一“协同配合”，形成以中西医结合为特色的一站式助孕求子闭环管理。集结国家级名中医、江湾医院中西医结合妇科首席教授尤昭玲教授，湘雅·江湾医联体专家、腔镜微创手术专家徐大宝教授、万亚军教授、彭国庆教授，美国贝勒医学院优生遗传专家文曙教授，“超声皇后”田艾军教授等博导专家，为病友提供专业、优质的诊疗服务。病友无需在不同的医院、科室之间来回奔波，也能看上“大专家”，省心、省力、省钱，真正做到“ 怀得上、保得住、长得好、生得顺、能再生”。
